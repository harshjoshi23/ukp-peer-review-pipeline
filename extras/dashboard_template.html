How to interpret this explorer
  • Filters affect the cards, chart, and table together. Rule definitions and their thresholds are calculated on the full valid dataset, as the assignment requires.
  • Malformed rows are excluded; valid duplicate rows remain in this view and in the required results.
  • Tied metareview modes use the first encountered value among tied modes. UKP has not confirmed a tie-breaking rule.
  • Recommendation mismatches are deterministic rubric violations, not evidence that a review is dishonest or scientifically wrong.
  • The required deliverables remain solution.py and results.json. This dashboard is an optional local companion.
